# 项目 Pitch（对外话术体系）

> **一句话定位**：用 20MB 单二进制，为 AI Agent 发身份证的企业级 PKI 基础设施。

---

## 演示核心：60 秒端到端流程

```
1. 创建根 CA（USB 冷备）        → varwof init-ca --name Root ...
2. 签发管理员证书（L3 管理员）   → varwof issue --ca Mgmt --subject "/CN=ZhangSan/OU=SuperAdmin"
3. 管理员登录 Web UI 自然语言下指令
4. Agent 用临时证书发起 mTLS 调用
5. 审计日志："张三的 Agent 执行了吊销操作"
```

当这个流程以 60 秒视频展示时，企业 CTO 会立刻理解：**这就是我们一直在寻找的 AI 治理方案。**

---

## 三个世界级难题：一套方案解决

| 难题 | 本方案 | 全球现状 |
|------|--------|---------|
| **权力归属** | 老板持有根 CA 私钥，通过 L2/L3 分层授权 | 多数企业还在用共享账号或 Web 表单密码 |
| **AI 无法追责** | 临时证书绑定用户 UID + 时空锁 + 审计日志 | 99% 的 Agent 还在用静态 API Key，无法区分"谁在操作" |
| **管理员权限泛滥** | 权限写入证书 OU，离线验证 | 多数系统依赖数据库查 RBAC，数据库被黑即全军覆没 |

> 这不是"微创新"，这是**范式转移**。

## 完整架构闭环

```
┌───────────────────────────────────────────────────────────┐
│ 用户层（老板/管理员）                                      │
│  └─ 持有 L3 管理员证书 (OU=SuperAdmin / OU=Operator)     │
│      ↓ 浏览器登录 Web UI，自然语言下指令                   │
├───────────────────────────────────────────────────────────┤
│ AI Agent 接入层（pki-agent）                              │
│  └─ 接收指令 → 向 LLM 发起对话 → 解析意图                 │
│  └─ 使用用户的"临时代理证书"发起 mTLS 请求                │
│  └─ 证书携带 X-Agent-User: 张三（原始用户绑定）           │
│  └─ 时间锁 + IP 锁                                       │
├───────────────────────────────────────────────────────────┤
│ PKI 核心层（pki）                                        │
│  └─ 中间件验证 mTLS 证书 OU → 映射为 RBAC 角色           │
│  └─ 审计日志记录: "张三的 Agent 执行了吊销操作"           │
│  └─ 业务逻辑执行（签发/吊销/续期/CRL/OCSP）              │
│  └─ 返回执行结果给 Agent                                  │
├───────────────────────────────────────────────────────────┤
│ 基础设施层                                                │
│  └─ 根 CA（USB 保险柜）→ 管理子 CA（在线）→ 管理员证书    │
└───────────────────────────────────────────────────────────┘
```

每一层都是独立的、可替换的、可审计的。

## 场景套话（演讲用）

**开场**：
> "想象一下：你的公司里有 100 个 AI Agent 在自动处理工单、审批流程、代码部署。你不知道哪个 Agent 正在做什么，也不知道如果出了事该找谁。更可怕的是，你只能用共享的 API Key 来管理它们。现在，我要用一个 20MB 的二进制文件，和一张发给每个员工的智能卡，彻底解决这个问题。演示开始……"

**定位**：
> 我们同时解决了 ToB（企业级服务）和 ToD（开发者生态）的痛点，找到了一个罕见的 **"ToG（向时代证明）"** 的机会——让中国开发者重新定义 AI 时代的身份与信任。
