# Crypto Export Notification

This repository is part of the **Varwof PKI Toolkit**, an open source
Public Key Infrastructure (PKI) software implementing cryptographic
functionality including X.509 certificate issuance, digital signatures
(ECDSA, RSA, Ed25519), and the AI Agent Identity Certificate (AIC)
extension as defined in IETF draft-wei-aic-identity-cert-00.
